# Firelight — privacy policy

This repository exists for one reason: the App Store requires a publicly
reachable privacy policy URL, and GitHub Pages will not serve one from a
private repository on a free account.

It contains the policy and nothing else. Firelight's source lives in a
separate, private repository; nothing about it is published here.

The policy is served at
<https://scwill12.github.io/firelight-privacy/>.

Edit `index.html` and push — Pages redeploys on its own. The canonical copy
also lives as `PRIVACY.md` in the app's repository, so change both or they
will drift.
